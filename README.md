# Hovenier.nl - demo

Een deel van de gemoderniseerde herbouw van hovenier.nl, live via GitHub Pages.

In deze demo: de homepage, de pagina Tuinaanleg en tuinrenovatie, het offerteformulier,
een prijsgids en de bedrijvengids. De volledige site telt 80 pagina's.

Teksten en foto's komen van hovenier.nl en de daar aangesloten hoveniersbedrijven.
Dit is een redesignvoorstel voor de eigenaar van die website.
